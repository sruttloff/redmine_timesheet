# Changelog

## 1.0.0 – 2026-10-16

- Support Redmine 6.1 / Rails 7.2 and remove obsolete Rails APIs and dependencies.
- Enforce project-scoped Timesheet permissions across reports, exports, and context menus.
- Fix all five groupings, private issue metadata, time without issues, overlapping groups, and exact totals.
- Repair period switching, inclusive ranges, saved filters, empty selections, reset, and permalinks.
- Export CSV and QuickBooks IIF from all groupings; configure and validate project hourly rates.
- Restore selection controls, SVG row actions, confirmation dialogs, and printing of collapsed groups.
- Complete English/German configuration and report labels.
- Replace obsolete Webrat tests with transactional request regression checks.
- Expand installation, permissions, usage, accounting limitations, support, and validation documentation.
